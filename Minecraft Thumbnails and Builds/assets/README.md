# Minecraft assets

## Stored in this repository

- [Blockbench models](Blockbench/README.md): 57 `.bbmodel` files and six related texture PNGs, copied from the user-provided archive. The source marks them CC BY 4.0; see the attribution and licence in that folder.
- [Extra Items Pack, Java 1.21.11](Resource%20Packs/Extra%20Items%20Pack%20-%201.21.11.zip): custom rename-triggered item models. The ZIP includes the author's exact item-name list.
- [Minimal HUD Icons, Java 1.21.11](Resource%20Packs/Minimal%20HUD%20Icons%20-%201.21.11.zip): optional HUD icon textures for scenes that need an in-game interface.
- [W_Tuxy skin source](player-skin/README.md): live public skin texture reference; the profile currently uses the slim model.

## Useful source repositories

- [PrismarineJS Minecraft assets](https://github.com/PrismarineJS/minecraft-assets): versioned vanilla assets, including 1.21.11 and 26.1. Use the requested version.
- [mc-assets](https://github.com/zardoy/mc-assets): TypeScript parsers for versioned block states, models, and texture atlases.
- [skinview3d](https://github.com/bs-community/skinview3d): Three.js-based Minecraft skin viewer and renderer.
- [Three.js](https://github.com/mrdoob/three.js): general-purpose 3D renderer.

Other uploaded resource packs and large source archives were reviewed, but are not copied into this repo. Add a specific pack here when a thumbnail or build needs it.
