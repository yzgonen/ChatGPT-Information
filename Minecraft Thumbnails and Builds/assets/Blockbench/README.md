# Blockbench models

Copied from [FrenchKrab/mc-blockbench-models](https://github.com/FrenchKrab/mc-blockbench-models).

This folder contains 57 Blockbench `.bbmodel` files (12 mob models and 45 tool models) plus six related PNG textures. The source README says the tool models are set up for resource packs and the mob models for ModelEngine / EliteMobs.
