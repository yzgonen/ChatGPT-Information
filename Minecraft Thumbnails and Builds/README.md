# Minecraft Thumbnails and Builds

Use this as the standing brief for Minecraft thumbnail and build requests. In a new chat, read this guide and the asset notes in [assets/README.md](assets/README.md) before starting.

## Defaults

- **Character:** Use the Java skin for **W_Tuxy**. Its current model is **slim**. Refresh the public skin at [MCHeads](https://mc-heads.net/skin/W_Tuxy) when rendering; do not substitute Steve or Alex if the lookup fails. Ask for a skin PNG if the profile no longer resolves or the user says the skin changed.
- **Minecraft look:** Use block geometry, pixel textures, and item models from the available assets. Keep the result recognisably Minecraft. Use the supplied Blockbench models when they fit the scene.
- **Thumbnail size:** Use 1280 × 720 PNG for YouTube unless the user requests another platform or size.
- **Language and text:** Match the user's language. Add text only when requested; use the exact supplied wording and keep it readable.
- **Version:** Prefer Java 1.21.11 for asset compatibility unless the user asks for another version. Check pack metadata before using a resource pack; do not assume every pack is compatible with every version or renderer.
- **Exact builds:** No personal world save is stored here. For a recreation of an existing world or build, use the supplied world file or ask for screenshots/details. If there is no reference, make an original scene and describe it as a new scene.
- **Deliverable:** Provide the finished image and, when requested, the editable scene or source files.

## Thumbnail workflow

1. Read the brief and identify the subject, setting, action, text, and required objects.
2. Load the W_Tuxy skin and the matching Minecraft geometry/textures.
3. Choose a clear focal point and camera angle; preserve the skin's design and the requested scene details.
4. Use lighting or visual effects only when they fit the brief. Do not add extra titles, logos, HUD, or effects the user did not ask for.
5. Check the output at thumbnail size for readable text and a clear subject.

## Build workflow

Use the Blockbench files in `assets/Blockbench/` for suitable props, mobs, or weapons. The model archive includes resource-pack tool models and mob models intended for ModelEngine/EliteMobs workflows. For standard Minecraft blocks, use the matching vanilla version assets linked in [assets/README.md](assets/README.md). Preserve the supplied model credit when sharing work that includes those assets.
